  3. Controlflare

    Controlflare

    A hard billing cap for Cloudflare. Set a monthly limit; when estimated spend crosses it, Controlflare pauses the Workers: the workers.dev URL, custom domains, routes, cron triggers and the D1, KV, R2 and Durable Object bindings all come off, and each is saved first so a resume puts it back. Your Cloudflare API token never leaves your own account, hosted or self-hosted, because a small open-source agent you deploy there is the only credential. Live at controlflare.com.
